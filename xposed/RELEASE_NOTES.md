TickTick Patch 2.0，使用 libxposed API 102。

- 以当前账号实例身份限定会员返回值，空白 User 和其他账号保留原值。
- 删除网络响应和数据库模型的返回值替换，不写入宿主用户字段或团队状态。
- 动态解析账号管理器和唯一当前用户入口，不硬编码混淆类名或版本号。
- 启用 API 102 自动热重载，处理旧 Hook 清理及新一代 Hook 重建。
- 保留原有固定签名；从不支持热重载的 1.1 首次升级后需要重新启动 TickTick。

新版宿主的启动及会员功能仍需用户真机确认；CI 检查不等于设备运行验证。以下是 1.1 的历史说明。

- 保留非团队会员状态、到期时间及会员额度逻辑。
- 修复提醒调度检查，getProTypeForFake 返回 0。
- 移除多版本配置、诊断 APK 构建及测试调用日志。
- 使用固定 Release 签名，不显示注入完成提示。

已测试环境：Android 15、TickTick Play 8.2.2.0（8220）、LSPosed 2.2.1（7912）/ API 102。

从旧 Debug 模块切换时，若签名不一致，卸载旧模块后安装正式版；无需卸载 TickTick 或清除其数据。
